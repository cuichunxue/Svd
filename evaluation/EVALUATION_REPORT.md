# SVD異常検知システム - 第三者評価レポート

**評価者**: 独立評価者
**評価日**: 2025-10-29
**対象**: SVD-based Time Series Anomaly Detection System

---

## エグゼクティブサマリー

SVDベースの時系列異常検知システムを23種類の異なるシナリオで包括的に評価しました。システムは高いリコール（0.863）を示しますが、プレシジョンが低く（0.082）、多くの誤検知が発生しています。特定のタイプの異常（ノイズバースト）では優れた性能を示しますが、全体的には改善の余地があります。

**総合評価**: ⚠️ 要改善（F1スコア: 0.108）

---

## 評価方法論

### 1. テストシナリオ（23ケース）

#### 時系列パターン（5種類）
- **Seasonal（季節性）**: 日次・週次の周期パターン
- **Trend（トレンド）**: 線形トレンド + 季節性
- **Periodic（周期性）**: シンプルな正弦波
- **Random Walk（ランダムウォーク）**: 確率的変動
- **Complex Pattern（複雑パターン）**: 複数周波数の組み合わせ

#### 異常タイプ（5種類）
- **Spike**: 急激なスパイク
- **Drop**: 急激な下落
- **Gradual Change**: 段階的な変化（レベルシフト）
- **Noise Burst**: ノイズの突発的増加
- **Pattern Change**: パターン（周波数）の変化

#### 難易度レベル（3段階）
- **Easy**: 大きな異常（magnitude=8.0）
- **Medium**: 中程度の異常（magnitude=4.0）
- **Hard**: 小さな異常（magnitude=2.0）

#### その他のテスト
- **パラメータ感度分析**: window_size (10, 20, 40), threshold (1.5, 2.5, 3.5)
- **ノイズロバスト性**: noise_level (0.05, 0.2, 0.5)
- **複合異常**: 複数の異常タイプの同時発生

## 詳細分析

### 1. 強み

✅ **高いリコール（再現率）**
- 平均リコール0.863は、異常を見逃さない傾向が強い
- 特にノイズバースト検知では完璧なリコール（1.000）

✅ **ノイズに対する頑健性**
- ノイズレベル0.05～0.5でも一貫した性能
- ノイズの影響を受けにくい

✅ **高い正確度（Accuracy）**
- 平均0.952の正確度
- ただし、これは正常データが大半を占めるため

### 2. 弱み

❌ **極めて低いプレシジョン（精度）**
- 平均プレシジョン0.082は、検出の約92%が誤検知
- 実運用では警告疲れ（alert fatigue）のリスク

❌ **点異常（Point Anomalies）の検出精度が低い**
- スパイク・ドロップ型の異常でF1スコア0.046
- ウィンドウベースの手法による過剰反応

❌ **パターン変化の検出不可**
- 周波数変化などの文脈的異常を検出できない
- SVDの制限事項

❌ **閾値調整の効果が限定的**
- threshold 1.5～3.5で性能がほぼ変わらず
- パラメータチューニングの余地が少ない

### 3. パラメータ感度

**Window Size（ウィンドウサイズ）**
- 小さいほどプレシジョンが改善（10→0.053, 40→0.013）
- しかし依然として低い水準

**Threshold（閾値）**
- 1.5～3.5の範囲で性能差がほぼ無い
- 閾値だけでは根本的な改善は困難

## 技術的問題点

### 1. アルゴリズム上の問題

**過剰検知の原因**
- ウィンドウ全体を異常としてマークする実装
- 1つのウィンドウが異常と判定されると、そのウィンドウ内の全点が異常扱い
- これにより誤検知が大幅に増加

**コード該当箇所**: `src/svd_anomaly_detector.py:153-157`
```python
for i, error in enumerate(reconstruction_errors):
    if error > anomaly_threshold:
        start_idx = i
        end_idx = min(i + self.window_size, n)
        anomalies[start_idx:end_idx] = 1  # ← ウィンドウ全体をマーク
```

### 2. 評価中に発見されたバグと修正

**元の問題**
- 学習データとテストデータでトラジェクトリ行列のサイズが異なる場合にエラー
- `operands could not be broadcast together with shapes (20,981) (20,581)`

**修正内容**
- フルSVD再構成から部分空間射影法に変更
- `U_k @ U_k.T @ trajectory_matrix` を使用した正しい射影

## 推奨事項

### 短期的改善（すぐに実装可能）

1. **異常スコアリングの改善**
   - ウィンドウ全体ではなく、中心点のみをマーク
   - または重複ウィンドウでの投票メカニズムを導入

2. **適応的閾値の導入**
   - 固定閾値ではなく、局所的な統計量に基づく動的閾値
   - ローリング統計を使用

3. **後処理フィルタの追加**
   - 孤立した異常点の除去
   - 連続性チェック

### 中期的改善（設計変更が必要）

4. **ハイブリッドアプローチ**
   - SVDと他の手法（統計的手法、LOF等）の組み合わせ
   - アンサンブル学習

5. **異常タイプ別の検出器**
   - 点異常用と文脈異常用で異なるパラメータ
   - 複数の検出器を並列実行

6. **教師あり学習の導入**
   - ラベル付きデータがあれば、閾値を最適化
   - ROC曲線分析による最適動作点の選択

### 長期的改善（根本的な見直し）

7. **深層学習ベースの手法**
   - LSTM Autoencoder
   - Transformer-based anomaly detection

8. **オンライン学習**
   - ストリーミングデータへの対応
   - 概念ドリフト（concept drift）への適応

## 使用上の注意事項

### 適した用途
✅ ノイズバースト型の異常検知
✅ 高リコールが要求される場合（見逃し厳禁）
✅ 後段で人間が確認する前段フィルタとして

### 不適切な用途
❌ 低誤検知率が要求される自動システム
❌ パターン変化の検出
❌ 即座の対応が必要なアラートシステム

---

## 結論

SVDベースの異常検知システムは、**概念実証（PoC）レベル**としては機能しますが、**本番環境での使用には大幅な改善が必要**です。

### 主要な課題
1. 誤検知率が極めて高い（92%）
2. パラメータチューニングの効果が限定的
3. 特定の異常タイプにしか有効でない

### 推奨される次のステップ
1. 異常マーキングロジックの見直し（最優先）
2. 適応的閾値メカニズムの実装
3. 他の異常検知手法との比較評価
4. 実データでの検証

### 最終評価
**評価**: ⚠️ **本番使用には不適・改善が必要**
**スコア**: F1 = 0.108 / 1.000
